📖 Overview
This API provides endpoints for managing pet adoption data. It allows users to view available pets, add new pets, update pet information, and manage adoption requests. The goal is to streamline the process of connecting pets with potential adopters.

🚀 Features
Retrieve a list of all pets available for adoption

Add new pets with details (name, type, age, breed, etc.)

Update existing pet information

Delete pets from the system

Manage adoption requests and approvals

🛠️ Technologies Used
Node.js

Express.js

MongoDB (Atlas)
